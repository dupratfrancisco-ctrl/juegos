# Batalla Naval

Batalla Naval para celulares: online con código (vía un servidor MQTT público),
contra la IA o pasando el celular. Es una página estática, sin servidor propio.

## Publicar en Vercel

1. En vercel.com → **Add New… → Project** → importá este repositorio.
2. En **Root Directory** elegí `batalla-naval`.
3. En **Framework Preset** dejá **Other** y tocá **Deploy**.
