# El Agente Secreto

Versión para celulares del juego de Ruibal. Es una página estática (sin servidor propio):
las partidas se sincronizan entre los dos teléfonos a través de un servidor MQTT público,
y el país secreto de cada jugador nunca sale de su teléfono.

## Publicar en Vercel

1. En vercel.com → **Add New… → Project** → importá este repositorio.
2. En **Root Directory** elegí `agente-secreto`.
3. En **Framework Preset** dejá **Other** y tocá **Deploy**.

## Instalar en iPhone

Abrí el link en Safari → botón Compartir → **Agregar a inicio**.
