# Juegos

Juegos para el celular, cada uno en su carpeta y publicados con GitHub Pages:

- `teg/` — T.E.G., de 2 a 6 jugadores, con objetivos secretos.
- `clue/` — Clue Springfield, de 3 a 6 jugadores.
- `burako/` — Burako, de 2 a 4 jugadores.
- `batalla-naval/` — Batalla Naval, para 2.
- `agente-secreto/` — El Agente Secreto, para 2.

Todos se juegan online con código (vía un servidor MQTT público), contra la IA o pasándose el celular.
Son páginas estáticas: no necesitan servidor propio ni compilación.

## Publicar

En GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)`.
